## Run Locally

Clone the repository:

```bash
git clone https://github.com/RatanShah7/RatanShah-Portfolio.git
```

Open the project:

```bash
cd RatanShah-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Production Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
